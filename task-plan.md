## Эпик 8: Логика расчёта (API /api/calculate)
> **Цель:** Реализовать алгоритм расчёта стоимости и сроков по ТЗ.

### [ ] Задача 8.1: API эндпоинт расчёта
**DoD:** POST /api/calculate принимает входные данные (сервисы, технологии, команда); валидация через Zod; возвращает результат расчёта в формате JSON.
**Зависимости:** 1.3, 5.4

### [ ] Задача 8.2: Алгоритм расчёта — базовые часы
**DoD:** Рассчитывается total_base_hours: для стандартных сервисов берутся часы (пользовательские → глобальные), для кастомных — из custom_services; корректная сумма по всем сервисам.
**Зависимости:** 8.1

### [ ] Задача 8.3: Алгоритм расчёта — распределение по ролям и коэффициенты
**DoD:** total_base_hours равномерно распределяется между выбранными ролями; коэффициенты технологий применяются к соответствующим ролям (Frontend → фронтенд-технологии, Backend → бэкенд + БД, Mobile → мобильные); скорректированные часы рассчитаны верно.
**Зависимости:** 8.2

### [ ] Задача 8.4: Алгоритм расчёта — стоимость и время
**DoD:** Стоимость каждой роли = скорректированные часы × ставка (пользовательская → глобальная); общая стоимость = сумма стоимостей + фиксированные стоимости кастомных сервисов; календарное время = общее время / (кол-во человек × 8); обработка особых случаев (нет ставки → 0).
**Зависимости:** 8.3

## Риски и неизвестные

| Риск | Влияние | Условие разрешения |
|------|---------|-------------------|
| Supabase RLS политики могут конфликтовать с админ-доступом | Высокое | Тщательное тестирование политик с разными ролями |
| Равномерное распределение часов по ролям может быть неточным для реальных проектов | Среднее | Заложить архитектуру для гибкого распределения в будущем |
| @react-pdf/renderer может иметь ограничения при генерации на сервере | Среднее | Прототипирование PDF-генерации на раннем этапе |
| Загрузка файлов (иконки) в Supabase Storage требует правильной настройки CORS | Низкое | Настроить CORS на этапе инициализации Supabase |
| next-intl может потребовать дополнительной конфигурации для App Router | Низкое | Проверить совместимость на этапе 1.4 |
