# PRD: Настоящий экспорт в PDF

**Дата**: 2026-09-09
**Статус**: Draft

## Цель

Заменить временное решение генерации PDF в `app/api/export/pdf/route.ts` (сервер возвращает HTML и полагается на `window.print()` — в коде прямо помечено как заглушка) на настоящую серверную генерацию PDF. Пользователь получает детерминированный файл `.pdf` с единым оформлением, корректной кириллицей и водяным знаком для бесплатного тарифа, независимо от браузера и устройства.

## Пользовательские сценарии

- Пользователь на странице результата нажимает «Экспорт в PDF» → скачивается настоящий файл `.pdf`, который открывается в любом просмотрщике и при отправке заказчику выглядит одинаково (сейчас — диалог печати браузера).
- Пользователь бесплатного тарифа экспортирует отчёт → в PDF есть водяной знак «MVP Calculator Demo» (для платных тарифов в будущем — без знака).
- Отчёт длиннее одной страницы → контент корректно разбивается на страницы, таблицы не обрезаются.
- Разработчик обновляет состав отчёта (новая секция/таблица) → правит единый шаблон, клиентский код не меняется.

## В скоупе

- Серверная генерация настоящего PDF с использованием уже установленной зависимости `@react-pdf/renderer` (4.4.1).
- Единый шаблон отчёта: заголовок с логотипом и датой, сводные показатели (стоимость, человеко-часы, календарные дни), таблица сервисов, таблица ролей (ставка/часы/коэффициент/стоимость), фиксированные стоимости кастомных сервисов, подвал «Сгенерировано в MVP Calculator».
- Водяной знак «MVP Calculator Demo» для тарифа `free`, отсутствие знака для `pro`/`business`.
- Корректное отображение кириллицы и многостраничная вёрстка.
- Замена реализации `app/api/export/pdf/route.ts` без изменения контракта вызова со стороны клиента.

## Не в скоупе

- Сохранение PDF в Supabase Storage и выдача временных ссылок (в ТЗ помечено как задел).
- Отправка PDF по email и шедулинг отчётов.
- Кастомизация шаблона пользователем (логотип/цвета/секции).
- Локализация текста шаблона (связано с будущим i18n).

## Технические ограничения

- В ТЗ задан лимит: генерация PDF не более 5 секунд.
- `@react-pdf/renderer` серверно генерирует документ; для кириллицы нужны шрифты с поддержкой кириллицы, встроенные в документ.
- Логотип и данные берутся из сохранённого проекта (`projects.data`) — отчёт должен строиться по снапшоту, а не по «живым» справочникам.
- Проверка тарифа выполняется на сервере (не на клиенте).

## Критерии готовности

- [ ] `POST /api/export/pdf` возвращает `Content-Type: application/pdf` и валидный файл (открывается в Adobe/браузере без ошибок), без диалога печати на клиенте.
- [ ] Отчёт содержит: заголовок с логотипом и датой, сводные показатели, таблицы сервисов и ролей, фиксированные стоимости, подвал.
- [ ] Кириллица во всех секциях отображается корректно (нет «кракозябр» и пустых квадратов).
- [ ] Для пользователя с тарифом `free` в PDF присутствует водяной знак «MVP Calculator Demo»; для тарифа `pro` знака нет (проверяется после включения тарифов либо через временную установку тарифа в БД).
- [ ] Отчёт из 2+ страниц корректно разбивается на страницы, таблицы не обрезаются.
- [ ] Время генерации на реальном проекте ≤ 5 секунд.
- [ ] Клиентский вызов экспорта со страницы результата не изменён и работает.
